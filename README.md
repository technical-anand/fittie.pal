💪 FittiePal

FittiePal is a modern fitness tracking web application designed to help users log workouts, monitor their progress, manage their fitness profile, and get personalized guidance through an AI fitness coach.

✨ Features

- 📊 **Fitness Dashboard**
  - View workout statistics at a glance
  - Track workout streaks
  - Monitor total workouts
  - View calories burned
  - Track total workout time
  - Weekly activity overview
  - Muscle group focus

- 🏋️ **Workout Logging**
  - Create and log workout sessions
  - Set workout duration
  - Add multiple exercises
  - Keep your training sessions organized

- 📜 **Workout History**
  - View previously logged workouts
  - Keep track of your training consistency
  - Monitor your progress over time

- 🤖 **AI Fitness Coach**
  - Get personalized fitness guidance
  - Ask questions about training
  - Get workout plan suggestions
  - Receive recovery tips
  - Get exercise recommendations
  - Stay motivated

- 👤 **Fitness Profile**
  - Manage personal fitness information
  - Set fitness goals
  - Select experience level
  - Update height and weight

🎯 Fitness Goals

FittiePal can be used to support different fitness objectives, including:

- 💪 Building muscle
- 🔥 Losing weight
- 🏃 Improving fitness
- 🏋️ Getting stronger
- ❤️ Improving overall health

🎨 Design

FittiePal uses a modern dark-themed interface with a clean dashboard layout and green accent colors.

The interface is designed to be simple, focused, and easy to use while working out.
